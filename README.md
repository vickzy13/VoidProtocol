Void Protocol
> *Some contracts don't exist. Neither do the crew that take them.*
Void Protocol is a co-op stealth heist game for 2 players, built in Unreal Engine 5. Set in 2187, mega-corporations control the solar system through surveillance networks, private militaries, and AI security systems. You and a partner are ghost operatives — hired through an encrypted underground network to infiltrate the most secured facilities in the galaxy.
No badges. No backup. No record you were ever there.
Gameplay
Each mission is a contract. Your two-person crew — an Infiltrator and a Hacker — must work in sync to breach corporate facilities, steal prototype technology, extract prisoners, or sabotage weapons AI. Every objective demands teamwork: the Hacker disables security systems remotely while the Infiltrator moves through shadows, neutralizes guards, and hides bodies before the next patrol sweep.
The world reacts to noise, light, and mistakes. Guards operate on a three-tier alert system — Unaware, Suspicious, and Alerted — and communicate with each other when something feels wrong. One careless footstep can cascade into a full lockdown. Extraction is only possible when the facility goes quiet again.
Features
2-player online co-op via dedicated or listen server
Two asymmetric roles with unique abilities and playstyles
Server-authoritative stealth detection — no client-side cheating
Dynamic 3-tier guard alert system with coordinated AI behavior
Hackable environment: cameras, doors, and security terminals
Silent takedowns, body carrying, and concealment mechanics
Over-the-shoulder TPS camera with dynamic aim zoom and cover peeking
Built with Unreal Engine 5 — Lumen lighting, networked via Online Subsystem
Status
Active development — vertical slice in progress. Target: one fully playable co-op mission, Station Sigma, demonstrating the complete stealth loop from breach to extraction.
